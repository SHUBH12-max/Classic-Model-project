# Sales Analytics using MySQL (ClassicModels Database)

## Project Overview

This project analyzes the **ClassicModels** database using **MySQL** to solve real-world business problems. It demonstrates SQL skills ranging from basic queries to advanced analytical techniques, including **Joins, Aggregate Functions, Subqueries, Window Functions, and Views**.

- Identified the highest revenue-generating customers and products.

- Compared revenue across different countries to identify key markets.
- Calculated Customer Lifetime Value (CLV) to recognize high-value customers.
- Identified repeat customers to support customer retention strategies.
- Demonstrated advanced SQL techniques to solve business problems using relational data.
